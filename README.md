# DocuForge

> From Idea to Documentary.

DocuForge is an open-source AI-powered documentary production platform.

It transforms a single topic into a complete documentary production package.

## Vision

DocuForge helps creators produce high-quality documentary content using AI.

Starting from a simple topic, it can generate:

- Research
- Documentary Script
- Storyboard
- Image Prompts
- Video Prompts
- Voice Narration
- Music Suggestions
- Thumbnail Prompt
- YouTube SEO Package
